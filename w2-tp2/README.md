## 🎮 Suggested Exercises

### **Beginner Level (1 hour)**

1. **Exercise: Create & Observe (15 min)**
   - Create test folder with files
   - Run in background mode
   - Observe deletion in real-time

2. **Exercise: Read the Logs (15 min)**
   - Open log file
   - Identify each deletion
   - Note timestamps

3. **Exercise: Explore Diagrams (15 min)**
   - Study QUICK_VISUAL_GUIDE.md diagrams
   - Trace through deletion process
   - Map to what you observed

4. **Exercise: Stop It (15 min)**
   - Run script
   - Stop with Ctrl+C
   - Verify it stopped

---

### **Intermediate Level (2 hours)**

1. **Exercise: Task Scheduler (45 min)**
   - Follow WINDOWS_TESTING_GUIDE.md
   - Create Task Scheduler task
   - Restart and verify auto-start

2. **Exercise: Log Analysis (30 min)**
   - Let script run 5 minutes
   - Analyze log file
   - Create deletion timeline

3. **Exercise: Study Flows (30 min)**
   - Read FLOWCHARTS_AND_DIAGRAMS.md
   - Trace execution path
   - Understand each decision point

4. **Exercise: Defense Planning (15 min)**
   - Read COMPLETE_LEARNING_MANUAL.md defense section
   - List defense strategies
   - Propose implementation

---

### **Advanced Level (4 hours)**

1. **Exercise: Service Installation (60 min)**
   - Install as NT Service (Windows)
   - Or systemd (Linux)
   - Verify persistence

2. **Exercise: Advanced Analysis (60 min)**
   - Monitor with system tools
   - Track resource usage
   - Correlate with logs

3. **Exercise: Removal Challenge (60 min)**
   - Install service
   - Try removing it multiple ways
   - Document procedures

4. **Exercise: Teaching (60 min)**
   - Prepare presentation
   - Explain to others
   - Answer questions
